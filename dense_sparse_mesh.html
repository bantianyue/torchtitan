dense mesh vs sparse mesh —— 同一批物理卡的两种视图

源码：torchtitan/distributed/parallel_dims.py 的 build_mesh()（真实 key 是 dense 和 sparse，不是"稠密/稀疏"两个字）。

dense 体系（普通参数 / FSDP / TP） sparse 体系（路由专家权重 / EP） 两者共享的 dp_replicate 轴

1. 拓扑：世界 mesh 派生两种视图

world mesh init_device_mesh((world_size,)) —— 物理设备编号 0..15
⬇ build_mesh() 做两次 unflatten ⬇
↘

_global_meshes["dense"]

  • 轴：(pp, dp_replicate, dp_shard, cp, tp)
  • 给：普通参数（attention/norm/共享专家/router）、FSDP、TP
  • 本页示例 5 轴：(1, 1, 4, 2, 2)
↘

_global_meshes["sparse"]

  • 轴：(pp, dp_replicate, efsdp, ep)
  • 给：路由专家权重（GroupedExperts）、EP
  • 本页示例 4 轴：(1, 1, 8, 2)
🔑 核心 这两条 mesh 是同一批物理设备的两种逻辑切法。世界 mesh 只是一张"卡编号表"， 而 dense / sparse 是它上面两个不同的多轴视图：同一张物理卡，在 dense 里有一个坐标，在 sparse 里有另一个坐标。 分界标准：这个参数要不要跟"专家 / EP"打交道—— 不用 → dense； 要（专家权重） → sparse。

2. 轴的关系与 efsdp 的推导

sparse 里的 efsdp 不是凭空来的，它由 dense 的几个轴换算得到（parallel_dims.py:272-274）：

batch = dp_replicate * dp_shard
fsdp  = dp_shard * cp
efsdp = fsdp * tp // ep          # 示例：8 * 2 // 2 = 8
轴属于哪套示例值含义
dp_replicate 共享1HSDP 的复制组；两套 mesh 共用
dp_sharddense4FSDP 切参数的轴（batch 维）
cpdense2上下文并行（序列维）
tpdense2张量并行
efsdpsparse8= dp_shard*cp*tp/ep，FSDP 在专家区域的 shard 轴
epsparse2专家并行（专家维）

所以 dense 的 tp / cp / dp_shard 在 sparse 里被"折叠"进 efsdp，ep 是 dense 里没有的独立专家轴—— 这正是两套 mesh 覆盖同一批卡、却各管一段逻辑的原因。

4. 与 fsdp.py 的 dp_mesh / edp_mesh 对上

# full_dtensor.py:70-125 —— resolve_fsdp_mesh / resolve_sparse_fsdp_mesh
_DENSE_STORAGE_AXES  = ["dp_replicate", "dp_shard", "cp", "tp"]   # → 从 _global_meshes["dense"] 取
_SPARSE_STORAGE_AXES = ["dp_replicate", "efsdp", "ep"]    # → 从 _global_meshes["sparse"] 取

dp_mesh  = get_activated_mesh(_DENSE_STORAGE_AXES)    # fsdp.py 的 dp_mesh  = dense 体系
edp_mesh = get_activated_mesh(_SPARSE_STORAGE_AXES)   # fsdp.py 的 edp_mesh = sparse 体系
fsdp.py 形参来源build_mesh 真实对象示例坐标用途
dp_meshresolve_fsdp_mesh_global_meshes["dense"](1,1,4,2,2)普通参数的 FSDP / TP
edp_meshresolve_sparse_fsdp_mesh_global_meshes["sparse"](1,1,8,2)专家权重的 FSDP / EP
⚙️ 为什么一个 MoE 层要拆到两套 mesh _shard_placement_fn（fsdp.py:281-295）按参数归属分开：
专家权重 → mesh_info=edp_mesh_info（sparse，跟 EP 的 all-to-all 走）；
其余参数 → mesh_info=dp_mesh_info（dense，普通 FSDP）。
所以"同一批设备两套视图"在代码里的落点，就是这个 per-param 的 mesh 选择钩子。
