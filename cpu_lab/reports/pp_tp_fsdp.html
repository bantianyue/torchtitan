call / step 是「总次数 ÷ 训练步数」，所以初始化与存盘那些一次性调用会被摊到每步里——下面的 phase 标注是看这一点的依据：训练步内才是每步真实开销，初始化（FSDP 广播模块状态、进程组建立）与存 checkpoint（DCP 内部用 broadcast 做 object scatter）都只发生一次或每interval 次。单卡运行时唯一出现的集合通信就全部属于存盘 I/O。

这些集合通信各自在干什么

  • all-gather — every rank reconstructs the full tensor from the shards (FSDP: full parameters; sequence parallelism: full activations)
  • reduce-scatter — sum across ranks, then keep only this rank's slice (FSDP: gradient averaging + re-sharding)
  • all-reduce — every rank ends up with the same summed value (TP: partial products of rowwise projections; all: gradient-norm sync)
  • broadcast — one rank's tensor is copied to the others (FSDP broadcasts module state at init; process group setup)
  • P2P send — hand a tensor to one specific rank (pipeline parallelism: activations forward)
  • P2P recv — take a tensor from one specific rank (pipeline parallelism: activations forward, gradients backward)
