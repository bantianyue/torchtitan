核心约束（源码）

  • batch mesh = dp_r·dp_s（parallel_dims.py:272），不含 CP
  • TP 必须整除 n_heads(32) 与 n_kv_heads(8)：TP=2 ✓
  • PP 与 weight tying 不兼容；PP 与 VarlenAttention 不兼容
  • EP mesh 约束：dp_s·cp·tp == efsdp·ep
  • SP 序列与 CP 复合：dense_sequence_parallel_placement = (DP,(CP,TP),None)
  • seq_len 被 (SP?tp:1)·(2·cp)=2·8=16 整除：8192/16=512 ✓（trainer.py:241）

3Batch 分解：一次优化步的数据怎么拆

global batch=64 一路拆到单 rank 单 PP微批。每步标注切几份（注意各并行度互不相同）。

图 3-1：global 64 → DP÷8 → 每rank每步 8 → 梯度累积微批÷2 → 每梯度累积微批 4 → CP÷4 → [4,2048] → ÷PP微批=1 → [1,2048]×4（×梯度累积微批2 = 8/步）

两个"微批"别混：梯度累积微批（grad_accum，外层）跨多次 forward/backward 累积梯度以模拟大 global batch，本例 = 2；PP微批（pipeline_parallel_microbatch_size，内层，仅 PP 时）一次 forward/backward 内切 local_batch 填流水线，本例 = 4。单优化步总 fwd/bwd = 梯度累积微批(2) × PP微批(4) = 8，梯度全累加后做 1 次 optimizer.step。

文字小结

  • 度数全互异：TP=2 / CP=4 / PP=3 / dp_shard=8 / dp_replicate=1，颜色也全错开（蓝/红/青/橙/绿/黄/紫），图上不会混。
  • batch_degree = dp_r·dp_s = 8，只用于数据加载与梯度累积，不含 CP。
  • 序列被两重切：CP=4 切 8192->2048（attention 内 K/V all-gather 回完整 8192），SP/TP=2 再切 2048->1024。norm/FFN 输入本地 S = 8192/(cp·tp) = 1024。
  • TP=2 切特征维：QKV/FFN 列并行切输出，wo/w2 行并行切输入并 reduce-scatter 回 SP；embedding/lm_head 切 vocab。
  • PP=3 切深度：32 层分 3 阶段（~11/11/10）；末阶段持 lm_head + ChunkedLoss。
  • FSDP=8 切参数：每 rank 持 1/8 参数，不改激活 shape。
  • 一次优化步：global 64 -> 8个(梯度累积微批2×PP微批4) -> 每PP微批 [1,8192]->[1,2048]->embed[1,1024,4096]->…->lm_head[1,2048,64128]->标量 loss->反向->8个(累积2×PP4)梯度累加->clip->AdamW(FSDP 1/8)->lr->checkpoint。
