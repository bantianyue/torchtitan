TorchTitan 负责什么

  • 训练编排 — 训练循环、step 调度、gradient accumulation
  • 配置系统 — CLI 解析、config_registry、override 机制
  • 模型架构 — Llama、Qwen、DeepSeek、Flux 等模型定义
  • 并行策略 — 决定用哪些并行维度、如何组合（调用 PyTorch API）
  • 训练子模块 — DataLoader、Optimizer、Checkpoint、Metrics 等
  • 激活检查点 — Selective / Full / MemoryBudget AC

PyTorch 提供什么

  • 集合通信 — all-reduce、all-gather、reduce-scatter
  • DeviceMesh — 多维设备拓扑抽象
  • DTensor — Shard / Replicate / Partial 分布式张量
  • FSDP2 / TP / PP / CP — 原生并行实现
  • torch.compile — Dynamo → Inductor 编译流水线
  • 自动微分 — autograd 引擎、CUDA Graphs

边界原则

  • 不直接调用 NCCL — 所有通信走 torch.distributed
  • 不写 CUDA kernel — 依赖 PyTorch + Triton
  • TorchTitan = 策略 + 编排
  • PyTorch = 原语 + 执行
  • 唯一硬依赖：torch
