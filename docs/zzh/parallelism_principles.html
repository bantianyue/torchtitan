并行策略实现原理 · 每个策略数学上怎么切、通信上怎么传

1TP 张量并行:列并行切输出维,行并行切输入维

TP 把线性层的权重矩阵沿行或列切成 2 份,每块 GPU 只算一半,然后通过集合通信拼回完整输出。核心是 DTensor placement——权重被声明为 Shard(0)(列并行)或 Shard(1)(行并行),DTensor 自动管理 redistribute。

图 1-1:TP 列并行和行并行的数学原理。列并行:切权重 dim 0,输入完整,输出各半需拼接;行并行:切权重 dim 1,输入各半,输出各一份需求和。

2SP 序列并行:激活在层间按序列切分,通信复用 TP 对

SP 把激活张量沿序列维(dim 1)在 TP 对之间切分。norm/FFN 间以 [1,seq/2,hidden] 形态存在;进线性层前 all-gather 拼回整序列,出行并行后 reduce-scatter 切回。SP 不额外开通信组,复用 TP 对的通信。

3CP 上下文并行:数据序列切段,attention 内 K/V gather

CP 把每微批的数据序列沿 seq 维在 cp 组内切分(2 份)。每块 GPU 只算自己那段的 query 的注意力;K/V 通过 all-gather 拼成全量(因为每段 query 需要看到完整的序列上下文)。

4PP 流水线并行:切层 + 1F1B 调度 + p2p 通信

PP 把模型层切分成 3 段,每段放在不同 GPU 上。微批在 3 个阶段间以 1F1B 调度流动:forward 传 hidden(p2p send),backward 传梯度(p2p send)。

5DP 数据并行:切数据 + 梯度归约

DP 把数据集按 batch 轴切 8 份,每个 rank 读自己的 1/8,独立算梯度,然后归约。在 torchtitan 中,梯度归约由 FSDP 的 reduce-scatter 承担,DP 本身只负责"谁读哪批数据"。

6FSDP 全分片数据并行:参数/梯度/优化器全分片

FSDP 把参数+梯度+优化器状态按 fsdp 轴分片(16 份)。前向时 all-gather 拼全参数,反向时 reduce-scatter 归约梯度。这是 Zero-3 思想的 PyTorch 实现。

7EP 专家并行:路由 + all-to-all 通信

EP 把 256 个路由专家切 4 份,每 rank 持 64 个。router 根据 token 的 top-8 选择目标专家,通过 all-to-all 把 token 发到对应专家所在 rank,专家算完后 all-to-all 发回。共享专家不走 EP,每 rank 完整持有。

8总结:7 种并行策略的"切什么"和"怎么通信"

策略切什么切法通信原语时机
TP权重 dim 0(dim 1)列并行/行并行各半all-gather / reduce-scatter每层 forward ×4
SP激活序列 dim 1TP 对内切 1/2all-gather / reduce-scatter(复用 TP 对)每层 forward ×4
CP数据序列 dim 1cp 组内切 1/2all-gather K/V / reduce grad每层 attention 内
PP层(非张量维度)层分 3 段p2p send/recv(hidden/grad)每微批每阶段边界
DP数据(batch 维)数据集切 8 份all-reduce(valid_tokens/loss)每步 1 次
FSDP参数/梯度/优化器状态 dim 0fsdp 组内 1/16all-gather(参数)/reduce-scatter(梯度)stage 前向开头 + 每层反向
EPMoE 专家(expert 维)ep 组内 1/4(256→64)all-to-all(token 路由)每层 MoE forward

七个策略彼此正交,叠加在一张 96 GPU 的网格上:

① PP 先纵切:3 段层互不重叠,每段在 32 块 GPU 上并行(pp3 × batch8 × cp2 × tp2 = 96)。

② TP 在每块 GPU 内横切权重:列并行/行并行各半,每层 4 次 TP 通信。

③ SP 在 TP 对内切激活:norm/FFN 间以 1/2 序列形态存在,进出线性层 gather/scatter。

④ CP 在 cp 组内切数据序列:attention 内 K/V gather 成全量。

⑤ FSDP 把参数在 fsdp 组内分 16 份:前向 gather 拼全,反向 reduce-scatter 归约。

⑥ EP 把专家在 ep 组内切 4 份:router 路由 token 到对应专家 rank。

⑦ DP 把数据在 batch 轴上切 8 份:各 rank 读各自数据。

每个策略 = 一条 mesh 轴 + 一个通信原语 + 一个切分维度。七者组合,就是 96 GPU 上的完整训练流水线。
