1TP=2 · 张量并行：切权重 + 切注意力头

切什么：线性层权重（列并行切输出维 / 行并行切输入维）+ 注意力 heads 怎么切：2 个 tp rank 各持一半 heads、一半输出特征。列并行 forward 无通信；行并行输出需聚合 通信：列并行：forward 无通信，backward all-reduce 梯度；行并行：forward all-reduce（或 SP 下 reduce-scatter），backward all-gather

这些都是 Llama / Megatron 约定的权重名。每层 Transformer block 有 6 个权重 + 1 个嵌入 + 1 个输出头。下图标出每个权重在 block 里的位置，下表给完整 shape 与 TP 切法。

SwiGLU FFN 公式

ffn_out = w2( silu(w1·x) * (w3·x) )

w1 / w3 都是 hidden->ffn_hidden 的“上投影”（14336），w2 是 ffn_hidden->hidden 的“下投影”。w1 的输出过 silu 当门控，乘 w3 的输出，再经 w2 降维。所以 w1/w3 列并行（切 14336），w2 行并行（切 14336）。

列并行 vs 行并行

列并行（wqkv/w1/w3/lm_head）：切输出维 -> forward 各 rank 算自己的切片，无通信；backward 梯度 all-reduce。

行并行（wo/w2）：切输入维 -> 各 rank 算 partial 输出，forward 需聚合（all-reduce，或 SP 下 reduce-scatter）。

配对：wqkv(列)->attention->wo(行)；w1,w3(列)->SwiGLU->w2(行)。每对“列进出行出”，中间无通信。

命名来源：Llama/Megatron 约定。wq/wk/wv 融合成 wqkv（torchtitan 用 FusedQKVLinear，存盘时拆回 wq/wk/wv 以兼容 HF）；FFN 的 w1/w2/w3 对应 gate/down/up；wo 是 attention out；lm_head 是输出头。attention_norm/ffn_norm 是两个 RMSNorm（无 TP 切分，权重复制）。

2SP=2(随TP) · 序列并行：切激活的序列维

切什么：激活张量 [B, S, D] 的序列维 S（在 norm 与列并行线性之间） 怎么切：度数 = TP（随 TP 走，共享 tp 通信域）。norm 在 S/tp 上算；进 attention/FFN 前 all-gather(TP) 拼回；出 wo/w2 后 reduce-scatter(TP) 再切 通信：all-gather(TP) 进；reduce-scatter(TP) 出（与行并行的聚合合并） 与 CP 复合：本例 CP=4 已先把 S 切成 2048，SP 再 ÷2 -> norm 本地 S = 8192/(4·2) = 1024

图 2：SP=2 在 norm<->线性之间切/拼序列（与 CP 复合后本地 S=1024）

关键：SP 度数 = TP（enable_sequence_parallel 不单独设度，复用 tp 轴）。它让 norm/残差在 S/2 上算省显存，只在 attention/FFN 内部短暂全量。

3CP=4 · 上下文并行：切 attention 的序列维（Q 局部、K/V 全量）

切什么：序列维 S，但只作用于 attention：Q 保持本地段，K/V all-gather 成完整序列 怎么切：4 个 cp rank 各持 1/4 序列（headtail 负载均衡，非简单对半）；Q 本地算，K/V 全量参与 通信：attention 内 all-gather K/V（cp 轴）；Q 梯度局部、K/V 梯度 reduce 切完 shape：tokens [1,8192] -> 每 cp rank [1,2048]；Q [1,2048,...]，K/V [1,8192,...]

图 3：CP=4 切序列 8192->4×2048，attention 内 K/V all-gather 回 8192

与 SP 的区别：SP 切的是 norm/线性之间的激活（整段都切），CP 切的是 attention 的序列且 K/V 要全量。两者复合：norm/FFN 本地 S=1024，attention 内 Q=2048、K/V=8192。

4PP=3 · 流水线并行：切模型层（深度维）

切什么：模型深度维--把 32 个 Transformer 层切成 3 段，每段一个 stage 怎么切：stage0: layers 0-10（11 层），stage1: 11-21（11 层），stage2: 22-31（10 层）。PP微批逐 stage 流过，stage 间点对点传 hidden 通信：stage 间点对点：前向传 activation，反向传梯度 切完 shape：每个 stage 内部 shape 不变（同前向主流程）；阶段边界传 hidden [1,1024,4096]（SP 粒度，gather 回 [1,2048,4096]）

图 4：PP=3 把 32 层切 3 段（~11/11/10），PP微批逐 stage 流过

约束：PP 与 weight tying 不兼容；PP 与 VarlenAttention 不兼容。末阶段持 lm_head + ChunkedLoss。1F1B 调度见主文档图 7-1。

5FSDP=8 · 全分片数据并行：切参数/梯度/optim

切什么：参数、梯度、optimizer state（全部展平后按 8 分片）--不切激活 怎么切：每 rank 只持 1/8 参数。forward 前 all-gather 出完整参数，forward 后 reshard；backward 同理；optimizer 只在分片上更新 通信：all-gather（fwd + bwd 取参数）；reduce-scatter（梯度聚合+分片） 切完 shape：激活 shape 不变（图 4-1 全部照旧）；参数每 rank 1/8，fsdp mesh = dp_s·cp = 8·4 = 32

图 5：FSDP=8 参数分 8 片 + 生命周期（all-gather/reshard/reduce-scatter/AdamW）

6dp_replicate=1 · 数据并行复制维（本例关闭）

切什么：本例 =1，即不复制。它定义权重是否在多 rank 间复制（DDP/HSDP 的 replicate 维） 怎么切：=1 -> 纯 FSDP（无复制维）；>1 -> 权重在 N rank 间复制，与 dp_shard 组成 HSDP 作用：与 dp_shard 一起决定 batch mesh = dp_replicate × dp_shard = 1 × 8 = 8（数据并行副本数） 通信：=1 时无 replicate 通信；>1 时 replicate 维做梯度 all-reduce（DDP 式）

图 6：dp_replicate=1 -> 单行 8 个 FSDP 分片（纯 FSDP，非 HSDP）

一句话速记

  • TP=2：切权重特征维（heads/vocab），列并行切输出、行并行切输入+聚合。
  • SP=2：切激活序列维（随 TP），norm 在 S/2 算，进线性 all-gather、出 reduce-scatter。
  • CP=4：切 attention 序列，Q 本地 1/4、K/V all-gather 全量。
  • PP=3：切层数，32 层分 3 阶段 ~11/11/10，PP微批逐 stage 流。
  • FSDP=8：切参数/梯度/optim，每 rank 1/8，all-gather/reshard/reduce-scatter。
  • dp_replicate=1：复制维关闭，纯 FSDP；batch_degree = 1×8 = 8。
