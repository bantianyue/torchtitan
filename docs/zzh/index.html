二、推荐学习路径

路径 A:从零开始(推荐) 01_architecture → 02_training_flow → 04_parallelism → 05_model_system → 06_components → 07_code_walkthrough 跟随原版 01-07 编号系列,从架构到代码逐步深入,建立完整心智模型。
路径 B:先理解并行(模型训练核心) parallelism_principles → parallelism_code_map → spmd_backends → gpu_view_training_flow → training_flow_overview 从并行策略的原理开始,再看代码在哪、后端区别,最后看 GPU 级训练流程全景。
路径 C:直接查代码位置(快速定位) parallelism_code_map → gpu_view_training_flow → training_flow_end_to_end 需要快速找到某个策略的代码时,从代码地图入手,再到具体流程图验证。
