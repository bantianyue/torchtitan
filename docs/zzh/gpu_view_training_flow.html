GPU 视图 · 各 GPU 怎么切分与集合通信

Llama3-8B · 192 GPU · TP=2 / SP=2 / CP=4 / PP=3 / FSDP=8。从具体 GPU 编号看：每块卡持有什么、和谁通信、怎么把结果拼起来。

DP=8 FSDP=8 TP=2 SP=2 CP=4 PP=3

注：FSDP=8 指配置中的 dp_shard 度；FSDP 实际分片组 = dp_shard×cp = 32 块（见第 4.3 节）。本页配置（示意）：global_batch=64、local_batch_size=4、seq_len=8192、pipeline_parallel_microbatch_size=1 → 梯度累积 = 64/(4×8) = 2，每轮 PP微批 = 4。所有序列相关 shape 都从 8192 推出：CP÷4→2048，SP÷2→1024。dataloader 每迭代给每 rank 一整批 [local_batch_size, seq_len]，schedule 再切成 PP微批。

1GPU 编号怎么来的：rank = ((pp×8+batch)×4+cp)×2+tp

torchtitan 用 init_device_mesh 按行优先展开 world rank,顺序 ("pp","batch","cp","tp") 度数 (3,8,4,2)。所以 GPU 编号公式：

rank = ((pp_idx * 8 + batch_idx) * 4 + cp_idx) * 2 + tp_idx

例：
  GPU0  = ((0*8+0)*4+0)*2+0  -> pp0 batch0 cp0 tp0
  GPU1  = ((0*8+0)*4+0)*2+1  -> pp0 batch0 cp0 tp1   (与 GPU0 同 cp, 做 TP 通信)
  GPU2  = ((0*8+0)*4+1)*2+0  -> pp0 batch0 cp1 tp0   (与 GPU0 同 batch/tp, 做 CP 通信)
  GPU8  = ((0*8+1)*4+0)*2+0  -> pp0 batch1 cp0 tp0   (与 GPU0 同 cp, 不同 batch)
  GPU64 = ((1*8+0)*4+0)*2+0  -> pp1 batch0 cp0 tp0   (与 GPU0 同 batch/cp/tp, 不同 PP 阶段)
  GPU128= ((2*8+0)*4+0)*2+0  -> pp2 batch0 cp0 tp0

192 块太多画不全。下面用缩样：每个 PP 阶段画 8 个代表 GPU（batch0 的 cp0-3 × tp0-1 = 8 块），其余 batch1-7 同构省略。

单优化步 = 梯度累积微批(2) × PP微批(4) = 8 次 fwd/bwd 微过程。每个 PP微批 shape [1,2048] 起步。下面按 GPU0 视角描述一个 PP微批的完整旅程（其余 7 个 PP微批分两轮 1F1B 交错进行，两轮之间流水线排空）：

阶段GPU0（pp0/cp0/tp0）在做什么通信其他 GPU
1. 取数据dataloader 给 GPU0 一整批 [4,8192]（batch0 副本，local_batch_size=4 × seq_len=8192），CP 切成 [4,2048]，schedule 再切 4 个 PP微批，每个 [1,2048]（cp0 段）-GPU2/4/6 各拿 cp1/2/3 段；GPU1 拿同 cp0 段（TP 对，数据相同）
2. FSDP 取参从 32 块 FSDP 组 all-gather 出 layers 0-10 的完整参数（stage 开头一次性）FSDP all-gather同 pp/tp 的 32 块一起凑参数
3. embed+norm本地算 embed（半 vocab）+ RMSNorm，得 [1,1024,4096]SP reduce-scatterGPU1 同算（不同 head），结果 reduce-scatter 到各自 SP 段
4. attn 前向all-gather(TP) 拼 Q 序列 → wqkv → attention：Q 本地 [1,2048,16,128]，K/V all-gather(CP) 成 [1,8192,4,128]TP all-gather + CP all-gather K/VGPU1 同算另 16 头；GPU2/4/6 各算自己 cp 段的 Q
5. wo+ffnwo 行并行 → reduce-scatter(TP) 回 SP；ffn 同理（w1/w3→w2）TP reduce-scatter ×2GPU1 配对 reduce-scatter
6. FSDP 还参本 stage 反向结束后，参数回 1/32 分片省显存（PP 默认不逐层 reshard）FSDP reshard32 块各自 reshard
7. PP 发送11 层算完，hidden [1,1024,4096] 点对点发给 GPU64(pp1)PP p2pGPU64 接力算 layers 11-21 → GPU128 算 22-31 + lm_head
8. lossGPU0 不算 loss（非末阶段）；末阶段 pp2 算 ChunkedLossTP（logits 分块）GPU128 算 logits[1,2048,64128] + CE → 标量 loss
9. 反向收 pp1 回传的梯度 → 逐层反向：每条前向通信对偶（TP all-reduce/all-gather、CP K/V grad reduce；参数已 gather 无需 FSDP all-gather），逐层 FSDP grad reduce-scatter 回 1/32全部反向对偶GPU1/2/4/6 同步反向
10. 累加+优化8 个 PP微批梯度全加到 .grad；clip_grad_norm 在 pp_mesh all-reduce；AdamW 在 FSDP 1/32 分片上更新DP+PP clip；FSDP 更新所有 GPU 同步优化
一句话：GPU0 和 GPU1 是 TP 对（切 head/特征，频繁 all-gather/reduce-scatter）；和 GPU2/4/6 是 CP 对（切序列，attention 内 all-gather K/V）；和 32 块同 pp/tp 的是 FSDP 组（切参数，all-gather/reshard）；和 GPU64/128 是 PP 链（切层，点对点传 hidden/grad）。SP 复用 TP 对的通信。每块 GPU 同时属于 4 个通信组，一层内交错触发 ~4 次 TP + 1 次 CP；FSDP all-gather/reshard 每 stage 首尾各一次（PP 默认不逐层）；阶段边界 1 次 PP。
