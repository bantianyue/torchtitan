4总结：各策略在前向/loss/反向/优化各干了啥

前向 + loss

  • DP：开头把 global batch 切给 8 个副本；末尾在 loss_mesh 上 all-reduce 有效 token。
  • FSDP：每层算前 all-gather 参数，算后 reshard（包裹计算，不改激活）。
  • TP：每个线性权重切一半（列并行无通信，行并行 reduce-scatter）；embedding/lm_head 切 vocab；loss 的 logits 也 TP 切。
  • SP：norm 在切小序列上算，进线性前 all-gather，出 wo/w2 后 reduce-scatter。
  • CP：attention 内 Q 本地段、K/V all-gather 全量。
  • PP：32 层分 3 阶段，PP微批逐 stage 流，stage 间 p2p 传 hidden。

反向 + 优化

  • TP：列并行 grad all-reduce，行并行 grad all-gather（前向对偶）。
  • SP：all-gather/reduce-scatter 全部反向。
  • CP：K/V 梯度 reduce。
  • PP：梯度沿 stage 反向 p2p（末->首）。
  • FSDP：bwd 前 all-gather 参数，grad reduce-scatter 回 1/8 分片；AdamW 在分片上更新。
  • DP：8 个(梯度累积微批2×PP微批4)梯度累加，clip_grad_norm 在 pp_mesh all-reduce 范数。
一句话：前向里 DP 切数据、FSDP 包参数、TP 切特征、SP 切序列(norm间)、CP 切序列(attn)、PP 切层--六种策略各管一个维度，互不冲突；反向把前向每条通信对偶一遍；最后 FSDP 分片上做 AdamW 更新。每层是并行最密集处（5 策略齐上），整个前向约 128 次 TP/SP 通信、8 个(累积2×PP4) × ~258 次/步。
