DeepSeek-V3 671B 模型结构(代码出处 models/deepseek_v3/__init__.py:462-523):

本页示意配置(为讲清所有策略):global_batch=64 · local_batch_size=4 · seq_len=4096 · pp微批=1 · PP3/TP2/CP2/EP4/DP8 → 梯度累积 2,PP微批 4;GPU 总数 = 3×8×2×2 = 96。EP 从"未启用"变为"启用",这是与 Llama3 版最大的不同。

与 Llama3 版的三处关键差异:① EP 从"未启用"变"启用":sparse_mesh 的 efsdp/ep 轴生效(parallel_dims.py:197-200,331-335),专家按 ep 切 4 份、走独立 edp_mesh(fsdp.py:194-272);② attention 是 MLA 而非 GQA——TP 切分对象是 q/kv 投影与 o 投影,注意力后端为 FlexAttention(config_registry.py:96,166);③ 官方 671B 用 Interleaved1F1B(config_registry.py:202),每 rank 持 2 个虚拟 stage。

三句话收尾:① 初始化把所有并行一次性定型:mesh 轴(parallel_dims.py:203-384,含 ep/efsdp)→ TP/SP 声明(decoder_sharding.py)→ PP 切层(pipeline_parallel.py:315-598)→ FSDP 稠密 + EFSDP 专家(fsdp.py:81-336)→ DP 切数据(text_datasets.py:95)。② 每步 train_step(trainer.py:757-865)只做动态的事:CP 切数据(trainer.py:668-676)、微批切分(schedules.py:559-576)、SP/TP 层内通信(module.py:418-513)、PP 调度(schedules.py:709-759)、专家路由 all-to-all(moe.py)、梯度归约+优化(trainer.py:804-814)。③ 每个策略 = 一条 mesh 轴 + 一组声明 + 一个运行时通信点,三者缺一不可。

调度器实现位于 PyTorch 库(torch/distributed/pipelining/),其余均在本仓库。示意配置为教学用途;官方 671B 配置见 deepseek_v3/config_registry.py:160-208(EP=2、Interleaved1F1B)。
