🔵 TorchTitan 负责什么

  • 训练编排 — train() 循环、step 调度、gradient accumulation
  • 配置系统 — CLI 解析、config_registry、override 机制
  • 模型架构 — Llama3、Qwen3、DeepSeek-V3 等 nn.Module 定义
  • 并行策略编排 — 决定用哪些并行维度、怎么组合（调用 PyTorch API）
  • 训练组件 — DataLoader、Loss、Optimizer、Checkpoint、Metrics
  • 激活检查点策略 — SelectiveAC / FullAC / MemoryBudgetAC

代码量：~69,000 行 · 位置：torchtitan/

🔴 PyTorch 负责什么

  • 集合通信 — all-reduce、all-gather、reduce-scatter（c10d + NCCL）
  • DeviceMesh — 多维度设备拓扑抽象
  • DTensor — 分布式张量（Shard / Replicate / Partial）
  • FSDP2 — fully_shard 全分片数据并行
  • Tensor / Pipeline / Context Parallel — 原生实现
  • torch.compile — Dynamo → AOT Autograd → Inductor 编译流水线
  • FlexAttention — 灵活注意力机制（含 CP load balancing）
  • 自动微分 — autograd 引擎、CUDA graphs

TorchTitan 通过 torch.distributed API 调用，不绕过 PyTorch

🔗 边界在哪里

TorchTitan 不直接调 NCCL，不写 CUDA kernel，不实现通信原语。

TorchTitan 的工作是"编排"：

  • 建 mesh → 调 init_device_mesh()
  • 分片参数 → 调 fully_shard()
  • TP 通信 → 用 DTensor placement + local_map
  • PP 调度 → 用 torch.distributed.pipelining
  • CP 包装 → 用 _context_parallel_shard
  • 编译 → 调 torch.compile()

边界清晰：TorchTitan = 策略 + 编排；PyTorch = 原语 + 执行

📦 依赖总结

TorchTitan 的直接依赖极少：

  • torch — 唯一硬依赖（核心）
  • torchdata — Stateful DataLoader
  • datasets / tokenizers — 数据加载
  • tyro — CLI 参数解析
  • tensorboard / wandb — 可视化（可选）
  • safetensors — 权重格式（HF 互转）
  • spmd_types — 分布式类型系统（可选）

NCCL/cuDNN/CUDA 是 PyTorch 的传递依赖，TorchTitan 不直接依赖
